# 🧰 UVUnifyAtlas – Unity Texture Atlas & Mesh Combiner Tool

## 📌 Overview

**UVUnifyAtlas** is a robust Unity Editor tool designed to:

- 🧩 Combine meshes with UV optimization  
- 🎨 Generate texture atlases (including packed mask maps)  
- 🌐 Support **Standard**, **URP**, and **HDRP** pipelines  
- 🌫️ Handle transparency with precision  
- 🧱 Create LODs, prefabs, and organized output folders  

Built for Unity developers who want clean, performant, and automated asset workflows.

---

## 🎮 Demo Scenes Included

The following demo scene is included to showcase UVUnifyAtlas features:

- `UVUnify_URP_DemoScene.unity`

It demonstrates:

- Atlas creation in URP  
- UV remapping and merging  
- Separation of transparent and opaque materials  
- Packed mask workflows (URP-specific)  
- LOD generation and prefab saving


All content in these scenes was created by **Walter Sattazahn** and is exclusive to this package.

---

## ✅ Compatibility

- **Unity Versions:** 2020.3 or newer recommended  
- **Render Pipelines:**  
  - ✅ Built-in Render Pipeline (Standard)  
  - ✅ Universal Render Pipeline (URP)  
  - ✅ High Definition Render Pipeline (HDRP)

Pipeline-specific shaders and materials are isolated per scene.
